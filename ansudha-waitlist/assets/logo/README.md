# ANSUDHA Brand Logo Assets

Place your final ANSUDHA logo files in this directory.

### Current Implementation:
- Active Main Logo: `ansudha.svg`
- Fallback/Template: `logo-placeholder.svg`
- Referenced in: `index.html` and `success.html`

### Recommended Logo Specs:
- Format: SVG (recommended for vector clarity) or high-res PNG (with transparent background)
- Colorways:
  - Primary: Warm Cream (`#F5F2B3`) with Gold (`#B66A0A`) accents for dark backgrounds
  - Secondary: Deep Maroon (`#5D1317`) for light backgrounds
- Dimensions: Approximately 320px × 80px aspect ratio

### How to Replace:
1. Save your logo as `logo.svg` or `logo.png` in this directory.
2. In `index.html` and `success.html`, locate the `<a class="brand-logo" ...>` block and update the `<img src="assets/logo/..." ...>` attribute.
