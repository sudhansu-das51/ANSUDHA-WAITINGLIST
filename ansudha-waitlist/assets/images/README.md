# ANSUDHA Brand Imagery Assets

Place high-resolution photography, artisan portraits, and craft product images in this directory.

### Current Implementation:
- Heritage vector craft motif: `craft-motifs.svg` (Odisha Ikat, Konark Mandala, and Filigree motifs)
- Pure CSS background textures and warm ambient gradients

### Recommended Imagery:
- Authentic Odisha craft visuals (Pattachitra scrolls, Sambalpuri Ikat looms, Cuttack Tarakasi filigree, Bell metal artisans)
- High-contrast, warm heritage tones harmonizing with `#5D1317`, `#B66A0A`, and `#F5F2B3`
- WebP or AVIF formats recommended for high performance and fast loading
